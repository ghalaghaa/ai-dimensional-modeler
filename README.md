# مولّد الموديل الأبعادي — AI Dimensional Modeler

أداة ويب تستخدم الذكاء الاصطناعي (Claude Sonnet 4.6) لتوليد موديل أبعادي (Facts & Dimensions)
من كويريات SQL، باتّباع منهجية **Kimball** على المستوى الذرّي.

مبنية لدعم مشروع ترحيل Cognos → Cloudera (منطقة RAW → UDM → Power BI) لمشروع ajb.

---

## الإعداد السريع

### 1. مفتاح الـ API

افتح ملف `.env` وأضف مفتاح Anthropic الخاص بك:

```
VITE_ANTHROPIC_API_KEY=sk-ant-xxxxxxxxxxxxxxxxxx
```

### 2. تثبيت وتشغيل

```bash
npm install
npm run dev
```

افتح المتصفح على: http://localhost:5173

---

## كيفية الاستخدام

1. **ارفع ملفات SQL** — اسحب وأفلت ملفات `.sql` أو اختارها من الجهاز (أي عدد)
2. **معاينة** — شاهد محتوى الكويري قبل التحليل
3. **تحليل** — اضغط "تحليل" لملف واحد، أو "تحليل الكل" لجميع الملفات
4. **النتيجة** — Facts وDimensions مع المقاييس والمفاتيح ونوع SCD
5. **تصدير** — JSON أو Excel (يشمل ورقة ETL Mapping Sheet)

## ملفات التجربة (samples/)

4 ملفات SQL حقيقية من تقارير Cognos الخاصة بمشروع ajb:
- R01 — عدد الحسابات الموجودة يومياً
- R09 — المحفظة اليومية لـ AJT
- R13 — معاملات بطاقات Fawri
- R15 — تحليل المحفظة اليومية RBG
