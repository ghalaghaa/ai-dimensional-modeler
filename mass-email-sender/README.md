# Mass Email Sender

موقع بسيط لإرسال نفس الرسالة لعدة إيميلات دفعة واحدة، عبر SMTP.

## الإعداد

1. انسخ `.env.example` إلى `.env` واملأ بيانات SMTP:

```
cp .env.example .env
```

لو تستخدم Gmail، فعّل التحقق بخطوتين وأنشئ "App Password" من إعدادات حساب Google، واستخدمه في `SMTP_PASS` (كلمة المرور العادية لن تعمل).

2. ثبّت الحزم وشغّل السيرفر:

```bash
npm install
npm start
```

3. افتح المتصفح على: http://localhost:3000

## طريقة العمل

- المستلمون يُضافون في خانة "BCC" داخل الإيميل المُرسل، بحيث لا يرى أي مستلم إيميلات باقي المستلمين، ويصل الجميع في نفس اللحظة عبر إرسال واحد.
- الحد الأقصى 100 مستلم في الإرسال الواحد (حدد في `server.js`).
